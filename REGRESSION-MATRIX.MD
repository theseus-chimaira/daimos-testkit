# DAIMOS REGRESSION MATRIX

THE COMPLETE PRE-USERLAND ACCEPTANCE SWEEP IS SERIAL AND RESUMABLE. THE EXACT
ORDER AND MAKE TARGETS LIVE IN
`tests/validation/daimos-regression-matrix-v1.tsv`; THIS FILE IS THE COMPACT
HUMAN-READABLE VIEW.

| ROWS | AREA | COVERAGE |
| --- | --- | --- |
| 001-003 | HOST / TARGET / SIZE | HOST CHECKS, DIRECT PDP-6 TARGET TESTS, MRES, PERMANENT SIZE, P10FOLD, STAGE1 SIZE |
| 004-008 | BOOT / LOGIN | BOOT SOURCE, ROOT CLASS, AUTO PRIORITY, CROSS-MATRIX, LOGIN LIFECYCLE |
| 009-016 | PROCESS / TTY | MONITORFS, CREDENTIALS, PROCESS LIFETIME/HIERARCHY/DOMAINS/EVENTS, TTY, WORD I/O, JOBS |
| 017-022 | SCHEDULER / MM / IPC | NORMAL AND RT SCHEDULING, 32K BOOT, STACK WATERMARKS, PIPES, SWAP, UUO ISOLATION, TRAPS |
| 023-027 | STORAGE | D6FS, BCACHE, LOGSTORE, DSK270, DRM236, DECTAPE, DTFS/TSFS |
| 028-031 | SYSTEM / TOOLS | KERNEL/STAND RUNTIME, D6FS HDD/RECOVERY, RUNTIME BUILDS, PDP-10 TOOL INTEGRATION |

`MAKE REGRESSION` RUNS THE MATRIX AND STOPS ON THE FIRST FAILURE. EACH PASS IS
CHECKPOINTED WITH THE DAIMOS SOURCE FINGERPRINT, TESTKIT SOURCE FINGERPRINT,
AND MATRIX CHECKSUM THAT PRODUCED IT. RERUNNING RESUMES AT THE FIRST ROW
WITHOUT A SAVED PASS.

`MAKE REGRESSION-STATUS` SHOWS `PASS` FOR A PASS FROM THE CURRENT SOURCE,
`OLD` FOR A PASS RETAINED FROM AN EARLIER SOURCE FINGERPRINT, AND `TODO` FOR AN
UNFINISHED ROW. THIS ALLOWS A LONG SWEEP TO CONTINUE AFTER A FIX WITHOUT
PRETENDING THAT EVERY EARLIER ROW WAS RERUN ON THE NEW REVISION.

`MAKE REGRESSION-RESTART` REMOVES SAVED ROWS AND STARTS AT 001. USE THAT FORM
FOR THE FINAL STRICT SINGLE-REVISION RELEASE/ACCEPTANCE RESULT.
