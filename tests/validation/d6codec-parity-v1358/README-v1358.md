# Staged grouped codec: independent host golden stream parity v1358

Uses the existing three 128-word real DXR payload fixtures from v045.
Their expected compressed streams were generated by the independent
host-side Python reference in `d6codec-native-v045/make-stream-fixtures-v045.py`.
The v1358 runner adapts **only entry symbol names**, preserving the
existing source and expected streams, then runs the staged DAIMOS v053
encoder and decoder through the v055 ABI wrapper on a PDP-6 simulator.
The native test compares compressed words bit-for-bit and performs a
complete decoded roundtrip for configctl, darc and d6lz.

Run:

```
DAIMOS_REPO=/path/to/DAIMOS sh tests/validation/d6codec-parity-v1358/run-v1358.sh
```

These are three small independent host-golden samples. They do not
establish parity for all 81 DXR executables or replace actual native
boot, PURE/EXEC/VFS/TSFS and error-handling acceptance. No production
codec selection or permanent memory changes are made.
