# v048 — decoder malformed-input and output-boundary suite

22 standalone PDP-6 test fixtures generated by `generate-v048.py`. They
cover empty success/failure, invalid control count, input exhaustion,
truncated descriptor and literals, zero length, zero-run nonzero distance,
illegal kind, zero and before-origin match distances, invalid odd halfword
offset, output overruns, excess trailing input, valid overlapping word and
even-halfword copies, one-word and 127-word zero runs, and valid literals.
All 22 passed on PDP-6 after correcting two mistakes in *test generation*:
full 36-bit return -1 must be compared using `CAMN` (not 18-bit immediate
`CAIE`), and descriptor words precede literal words even when the descriptor
is for the second token. Tests verify the decoder's success/error return
and a sentinel word immediately after its advertised output capacity.

The decoder itself was left byte-for-byte functionally unchanged from v047.
These tests are limited to controlled assembler arrays: do not interpret
passing them as proof of all malformed-stream rejection, arbitrary pointer
safety, stack depth bounds, memory isolation, or a hardened production ABI.
Native full DXR checks from v047 remain the separate positive regression.
All work is testkit-isolated. Production DAIMOS/KCORE untouched.
