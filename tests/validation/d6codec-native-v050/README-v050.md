# v050: bounded production ABI proposal, not yet implemented

`ABI-DESIGN-v050.md` specifies the existing experimental calling
conventions, a minimal one-shot production interface, strict safety gates
and a conditional group-atomic streaming design. It deliberately does not
claim an established C ABI, a measured stack high-water, or a functioning
resumable implementation. These remain tasks requiring concrete simulator
coverage before DAIMOS production integration.
